Every text colour here clears WCAG AA at 11px on the three opaque surfaces — app #0b0e12, panel #141920, card #1b212a. The fourth surface is the exception that matters: greys that pass on the panel base lose AA once a chip lifts the background under them, so any label sitting on a tinted or translucent surface steps up to #b0b9c4. None of these lean on the "large text" exemption, because the HUD has almost no large text. The only exempt value is the disabled-control grey, which WCAG excludes as an inactive control. Amber is the only accent. Green, red, blue and violet are semantic — money in, danger, water/vehicles, ore/geology — never decorative. Two background colours per screen maximum: #0b0e12 for the app, #141920 for panels. Hazard stripes appear on exactly one thing: an armed blast.

06 · MOTIONnothing animates that the player is waiting on
ELEMENTTRIGGERMOVEDURATIONEASING

Two hard rules. Per-frame values never transition — the clock, balance, gauges and countdowns are written in place, because a 200ms tween on a value that changes every frame reads as lag. And nothing blocks input: panel and modal entrances are 120–180ms and interactive from frame one. Respect prefers-reduced-motion by dropping all transforms and keeping opacity only; the pip pulse becomes a static fill.
